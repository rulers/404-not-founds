# 404 NOT FOUNDS — 365 Days of Nothing

**A collection of things that shouldn’t exist.**

365日間、毎日異なるインタラクティブな404ページを制作・公開するWebアートプロジェクトです。

[作品を見る](https://rulers.github.io/404-not-founds/) · [すべての作品](https://rulers.github.io/404-not-founds/discover/)

## 楽しみ方

TOPではアクセスするたびに作品をランダム表示します。SHUFFLEで別の作品へ、Discoverから気になる作品へ移動できます。操作方法は作品内に表示されます。

## 公開作品

| Day | 作品                                                              | 体験                                                      |
| --- | ----------------------------------------------------------------- | --------------------------------------------------------- |
| 001 | [Glitch 404](https://rulers.github.io/404-not-founds/404/001/)    | マウス・タップで信号が崩れる404                           |
| 002 | [Break the 404](https://rulers.github.io/404-not-founds/404/002/) | ボールとパドルで壊す404。スマートフォンのチルト操作に対応 |

## ローカルで動かす

Node.js 24とnpmを使用します。

```sh
npm ci
npm run dev
```

http://localhost:3000 を開いてください。
