# Day 002 — Break the 404

## コンセプト

エラーの数字を自分の手で消すブロック崩し。白い小片でできた巨大な404が、黄緑の光によって少しずつ欠けていき、最後には「NOT FOUND / YOU FOUND NOTHING.」だけが残る。背景は操作中も黒のまま。

中央の0は4と同じ9列×11行の幅を持ち、上下を閉じた太い輪にする。左右の縦棒と5列分の空洞によって1との誤読を防ぐ。DiscoverのSVGもゲームのブロック配置から作成した。

## 操作

- PC：マウスまたは左右矢印でパドル移動。クリック・Enter・Spaceで発射。
- スマホ：最初のタップで開始。DeviceOrientationEventのgammaを使い、左右約30度の傾きをパドル位置へ変換。画面の回転角も考慮する。
- iOS：最初のタップ内でrequestPermission()を実行。許可拒否・非対応・1.5秒間センサー値が来ない場合はドラッグへ切り替える。許可後もドラッグで手動操作へ切り替え可能。
- 落球：壊したブロックは保持し、再タップで発射。全破壊：NOT FOUNDを表示し、タップで再構築・再開。
- タブ非表示：ボールを待機へ戻し、復帰時の急な進行を防ぐ。画面サイズ変更は盤面を再構築する。

## 技術

Canvas 2DとTypeScript。Three.js・追加依存・外部通信は使わない。`lib/break404.ts`に文字マスク・盤面生成・衝突処理を分離。1000単位の論理幅で端末の縦横比へ適応し、描画解像度はdevicePixelRatioの2倍までに制限する。

ボールとブロックは円と矩形の衝突判定。移動を小さく分割して高速時のすり抜けを防ぐ。パドル反射は当たり位置で角度を変え、完全な垂直往復を避ける。描画はrequestAnimationFrame、連続値はrefに保存し、React stateはフェーズ・残数・操作モードの変更時だけ更新する。アンマウント時にRAF・ResizeObserver・センサー／visibilityイベント・タイマーを解除する。

CSS Modulesで作品内にスタイルを限定する。`ownsArtworkInfo: true`によって共通の下部作品情報を省略し、タイトルを左上、操作説明を左下、短いコピーを右下に配置。共通ナビゲーションは維持し、作品内の説明は入力を透過する。

## 配色・アクセシビリティ

背景 #090909、ブロック #efefec、ボール／パドル #d5ff70。装飾の自動点滅・揺れは使わず、reduced-motionではクリア時のフェードも停止する。ゲームに必要なボール移動は、利用者が開始した後だけ動く。キーボード操作・フォーカス枠・開始／クリアの読み上げを用意する。

## 検証と制約

単体テストで0の輪郭、入力の境界、壁・パドルの反射、落球後の再発射、高速衝突、全破壊の状態遷移を検証。PlaywrightでPC／モバイル、静的URL、Discover、権限の許可／拒否／無応答、ドラッグ、キーボード、reduced-motion、320px幅と横向き、既存Day 001を検証する。

モーション権限と傾きはChromium上で模擬する。iPhone／Android実機のセンサー精度とSafari固有の権限画面は未確認。センサー操作にはHTTPSが必要で、GitHub PagesのHTTPS配信を利用する。スマホでドラッグに切り替えた後は再読み込みでチルトを選び直せる。

検証結果：Prettier・lint（警告0件）・typecheck・単体テスト11件・basePath `/404-not-founds` 付き静的ビルド・ブラウザテスト17件成功。PCではモバイル専用の3ケースを対象外とする。PC／スマホのゲーム画面とサムネイルも画像で確認した。
