# Day 003 — Glass 404

## Concept

「404を壊す気持ちよさ」。冷たい透明な数字を打ち、白い亀裂を育て、破片を手放す。何もなくなった時間を挟んで同じ輪郭が戻る。暗い青の空間、氷色の稜線、微かな紫の反射でガラスの薄さと厚みを同時に見せる。

クリック／タップしたガラスから亀裂が放射状に伸びる。6回の打撃で粉砕し、約2.3秒後に再生を始め、約1.2秒で復元する。穴・余白へのクリックは破壊に数えない。Enter／Spaceは右側の4の中央を打つ。ポインター移動では反射光が追従する。音は使用しない。

## Technology

Canvas 2D、Path2D、TypeScript、CSS Modules。物理エンジン・WebGL・新規パッケージは不要。数百片以下の三角形をクリップして描くことで、透明な面・細い亀裂・破片の回転を同じ描画方式で扱える。静止時は描画を停止し、ライブラリやテクスチャのダウンロードも発生しない。

SVGを初期HTMLとCanvas非対応時の表示に使う。CanvasとSVGとサムネイルは同じ輪郭パスを利用する。0の閉じた輪と穴をeven-oddで描き、414への誤読を防ぐ。

## Implementation

- `components/artworks/Glass404.tsx`：全画面のボタン、座標変換、マテリアル描画、段階管理と再生。共通Header・左下タイトル・右下説明をそのまま使用する。
- `lib/glass404.ts`：輪郭、放射状の分岐亀裂、三角形の破片生成、重力と指数減衰。操作ごとに方向・長さが変わる。
- 線形グラデーションを重ねた面、5×7単位ずらした厚み、白い輪郭、ポインター中心の反射光で質感を作る。亀裂は暗線とずれた明線の組で凹凸を示す。
- `isPointInPath(..., "evenodd")`で実際のガラスだけを打つ。粉砕時は三角形に切り抜いた元の材質を回転・落下させる。単位時間を1/30秒に制限し、復帰時の飛びを防ぐ。
- Reactの更新は段階・打撃回数だけ。RAFは衝撃・崩壊・再生中だけ継続し、反射光・リサイズは必要時に再描画。非表示タブでは停止、復帰時は再生時間を取り直す。RAF、ResizeObserver、イベントを解除する。
- DPR上限2、論理描画1000×500、表示幅と高さの両方を制約。reduced-motionでは飛散・衝撃リング・再生フェードを省略し、亀裂と状態変化で体験を保つ。
- Canvas/Path2D非対応時はSVGを残す。入力不能でも404は視認できる。ステータスはpoliteで通知し、フォーカス表示を維持する。

## Lessons Learned

透明素材の認識には面の透明度だけでなく、輪郭の明暗と少しずれた厚みが効く。数字の穴も含めた当たり判定を描画と共有すると、空白を打って割れる違和感を避けられる。見た目の破片と実際の剛体シミュレーションを分け、必要な減衰と重力だけに絞ると依存を増やさず操作への即応性を保てる。

## Reuse

Path2Dによる描画とヒットテストの共有は、図形エディタ・製品展示・インタラクティブな図解に応用できる。描画要求の集約、画面復帰時の時刻補正、SVGからの段階的な機能追加も他のCanvas UIで再利用できる。破片・乱数関数は作品内のモジュールとし、共通基盤には昇格させていない。

## Validation / limitations

単体テストは亀裂の起点と変化、形状内の破片、重力・回転減衰を確認。ブラウザテストはPC／モバイルの打撃・空洞・粉砕・再生・キーボード・Discover・静的URL・Canvasなし・reduced-motion・320px幅と横向きを対象にする。結果はPRと日報に記録する。

真の光学屈折・破片同士の衝突はシミュレートしない。Canvas非対応時は鑑賞専用。実機Safari／Android、Lighthouse数値は未確認。PRは未マージで、本番サイトには公開しない。

確認結果：Prettier・lint・typecheck・単体テスト14件・basePath付きstatic build成功。[実装コミットのPR CI](https://github.com/rulers/404-not-founds/actions/runs/39044529715)でもブラウザ29件が成功（desktop対象外のモバイル専用7ケースは除く）。
