# Day 003 — Glass 404

## Concept

「狙って、ためて、自分の手で壊す」。黒い空間に張りつめたガラスの404。短い打撃は小さな欠け、長押しからの解放は大きな穴を生む。回数を満たす作業ではなく、どこを残してどこを抜くかで見た目を自分で変える作品。

硬い輪郭、断面の冷たい光、落ちる破片と衝撃後の静けさを主役にする。他の日と共通の素材研究シリーズにはしない。黒・銀・わずかな橙の照準と、大文字の短いコピーで緊張感を作る。

## Technology

Canvas 2D / Path2D / TypeScript / CSS Modules。テクスチャ用と欠損を保持する面用のオフスクリーンCanvasを使い、破片ごとにグラデーションを描き直さず切り抜いた材質を回転させる。物理エンジン・WebGL・追加依存は使わない。初期表示と非対応時にはSVGの404を残す。

## Implementation

- タップ／クリックで打点付近の三角形セルを取り除く。最大約0.9秒の長押しで半径48→160単位まで拡大。解放までに動かした方向は飛散の勢いへ加える。
- 元の輪郭に加え、欠けた面のalphaを検査する。0の穴・余白・すでに抜けた穴は打撃として数えない。再び狙う場所を変えることに意味がある。
- 取り除いたセルは直ちに透明な穴になる。亀裂はその周辺へ伸び、破片は衝撃方向・重力・回転・減衰・明滅する反射を伴って飛ぶ。小さな打撃でも破片が出る。
- 残ったセルが32%未満になると全体が崩れる。約2.1秒後に再生を始め、約1.1秒で戻る。固定の6回カウンターは撤去し、残量を表示する。
- 長押し中は照準が膨らみ、解放時には数字の描画だけが短く反動で揺れる。共通Headerやリンクは揺らさない。`MATERIAL STUDY`表示は撤去した。
- Enter／Spaceは残存するセルを選んで打つ。ポインターキャンセルやフォーカス喪失は打撃にしない。reduced-motionでは飛散・画面反動を省き、欠損と再生は維持する。
- 静止中と非表示タブでは継続描画しない。DPR上限2、論理幅1000。RAF・ResizeObserver・メディアクエリ・visibilityイベントを解除し、オフスクリーンCanvasも解放する。

## Lessons Learned

前版の「線が増え、6回で全体が砕ける」は、入力場所を変える理由が弱かった。線の細密さよりも、初撃から本体が欠け、その欠損が次の操作を変えることを優先した。破片の描画には元の材質をキャッシュし、見た目の変化と描画コストを分離した。

毎日の作品を同じレイアウト・コピー・配色でシリーズ化すると、異なる体験のはずが素材違いに見える。共有するのはギャラリーの導線だけとし、この日は衝撃と不可逆な変化に絞る。

## Reuse

見えているalphaと形状の両方を使ったヒットテストは、削る・消す・穴を開けるUIに応用できる。押してためる→解放する入力、キャンセル時の無操作、静止画をキャッシュして部分的に動かす描画も再利用できる。汎用の物理基盤は追加していない。

## Validation / limitations

単体テストは打点・力による破壊範囲の変化、同じ場所を再度壊せないこと、遠い領域が残ること、重力と減衰を対象とする。ブラウザではマウス／タッチ、長押し、キャンセル、空洞、欠損、キーボードでの破壊・再生、SVGフォールバック、reduced-motion、狭い画面、既存作品への遷移を確認する。結果はPRに記録する。

実機Safari／AndroidとLighthouse数値は未確認。正確な屈折や破片間衝突は計算しない。強い長押しでは数字が読めなくなること自体を操作結果とし、再生後は元の404へ戻る。
