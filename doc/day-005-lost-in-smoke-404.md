# Day 005 — Lost in Smoke 404

## Concept

**It was here.** 最初に404が見える。その場所を覚えた直後、煙が静かに覆う。マウスや指の風で煙をかき分けると、同じ404が再び現れる。消えたのはページではなく視界。ユーザー承認に従い、404の移動・ランダム再配置・隠れてからの瞬間移動は実装しない。

Glassの破壊・Liquidの物体操作とは異なり、風の痕跡が失われる時間を扱う。青緑がかった灰色、重なる雲、弱い光と余白を主体にする。Home・個別URLは同じコンポーネントを使用し、共通ナビとDiscoverを維持する。画面端の煙をフェードし、Headerと下部の操作説明の可読性を守る。

## Technology

TypeScript / 独自WebGL / Canvas 2D / CSS Modules。Three.js、Stats.js、追加パッケージ、外部画像・CDNは使用しない。自作のシード付きvalue noiseを5層重ね、縁を減衰させた256×256の煙テクスチャを初期化時に一度だけ生成する。

透明な平面を重ねて回転させる方式は参考Penの発想を受け継ぐ。現行環境にはThree.jsが未導入であり、固定視点の平面だけに必要な頂点・テクスチャ・ブレンド処理を作品専用WebGLへ限定する。立体的な流体計算や巨大な共通レンダリング基盤は導入しない。

## Implementation

- 404はDOMの固定要素。位置は画面幅55%・高さ49%。文字の座標・透明度を操作で変更せず、上に重なる実際の煙Canvasで遮蔽する。
- 最初の1.8秒は遮蔽0、その後3.4秒で煙を重ねる。操作後も同じ座標で文字が現れる。
- 自作の煙画像を貼った56枚（モバイル初期配置38枚）の平面を重ねる。配列順を固定した前後関係で重ね、1バッチで描画する。実際の体積ではなく、平面の重なりで奥行きを表現する。平面ごとの回転・明るさ・透明度を変え、単純な一枚画像の移動にしない。
- 風は幅64セル、画面比率に応じた高さのベクトル・圧力フィールド。入力区間全体へ力を加えるため、高速な移動でも点の列に途切れない。マウス移動、タッチのスワイプ、クリック／タップのひと吹きに対応する。
- 風は煙の中心位置とテクスチャ座標へ作用する。圧力に沿って煙の濃度を下げ、画像の濃淡と、画面全体で共通のノイズで境界を変える。薄い煙を残し、完全な透明円を描くだけの消しゴムを避ける。力は実時間で減衰し、煙は元の領域へ戻る。位置の積分は短い時間に制限し、遅いフレームで発散させず、導入と風の減衰は描画速度で遅らせない。
- Enter／Spaceは中央の404へひと吹き。矢印キーは風の位置を移動する。キャンセル・フォーカス喪失・タッチ終了時はポインター状態を解除する。
- 描画幅上限1000、DPR上限1.25、WebGL約30fps／Canvas約15fpsを目標に描画を間引く。マウス移動ごとのReact state更新は行わない。自動回転は通常時のみ継続する。
- reduced-motionでは自動回転・平面の移動を止め、導入の濃度変化とユーザーが起こす視界変化を維持する。静止へ戻るとRAFを止める。非表示タブでも停止し、復帰時に大きな時間差を適用しない。
- WebGLの生成・Shader失敗・context loss時は同じ自作画像とモデルをCanvas 2Dで描画する。Canvas版はテクスチャの流れを簡略化する。JavaScriptなし／Canvasも使えない場合は、CSSの静かな煙と読める404を残す。
- RAF・ResizeObserver・入力・visibility・motion・contextイベント、バッファ・Shader・Program・テクスチャ・オフスクリーンCanvasを解放する。
- 画面比率が変わると煙を再生成し、初回シーケンスを再開する。404は常に同じ相対位置。作品番号は005、URLは `/404/005/`。

## Lessons Learned

「最初から隠された文字を探す」より、「見えていた場所が覆われる」ことでユーザーが触る位置を理解できる。404の再配置は不要とし、煙そのものの反応へ体験を集中させた。

煙画像のURLが公開されていても、再配布条件の確認にはならない。素材の自作と、描画手法への参照を分ける。透明な煙画像のRGBを境界ノイズにも使うと、Canvasの低alpha部分で色が量子化され粗い模様が出る。同じ自作データから不透明な密度テクスチャを別に保持して補間を安定させた。

また、状態ラベルだけでは遮蔽の成功を検証できないため、ブラウザ試験ではCanvasの実際のalphaも確認する。

## Reuse

入力の線分に沿って力を加えるフィールドは、霧・砂・光跡・柔らかな消去へ応用できる。GPUとCanvasで物理状態を共有し、見た目だけを簡略化するフォールバック、非表示時の停止、固定文字と前景の分離も応用可能。既存作品を巻き込む共通化は行っていない。

## Validation / limitations

単体試験：導入タイミング、線分に沿う風・遠方への非干渉・減衰、煙の移動と復帰、reduced-motion、独自画像の再現性と透明な縁。

ブラウザ試験：初期の404→遮蔽→実マウス／CDPタッチで再露出→再遮蔽、404の座標不変、描画alpha、キーボード、Canvas代替、JavaScriptなし、狭幅・横画面、DiscoverとbasePath配下の直接URL。物理時間をClockで固定し、描画速度と入力時間を分離する。検証結果・画面画像・CIはPRへ記録する。

実機Safari／Android、実GPUでの負荷、Lighthouse数値、ユーザーによる作品の最終評価は未確認。光学的な体積散乱・本格的な流体計算ではない。元の写真素材と同じ煙模様を再現するものではない。
