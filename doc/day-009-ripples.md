# Day 009 — 404 Ripples

## Concept

**A breeze crosses the water. Nothing drifts alone.** 青緑の水面に生成りの 404 と 1 枚の葉が浮かぶ。水面をなぞる風が、短いさざ波、3 文字の揺れ、葉の漂流へつながる。操作しなくても弱い自然風が残り、操作終了後は約 5〜7 秒かけて静けさへ戻る。

2026-10-25 に GitHub 連携で main `db0b404` と登録済み 008 までを確認し、009 を採番。ローカル HEAD も同じコミット。origin/main の追跡参照は古く、fetch は環境の接続制約により未完了。承認済み設計と追加レビューに基づき、`feature/404-009-ripples` で制作。develop の同期は対象外。

Liquid の液体の変形、Smoke の遮蔽の解除と異なり、読める 404 を保ちながら、一つの風が環境へ伝わる余韻を扱う。

## Technology

Next.js / React / TypeScript / Canvas 2D / Path2D / CSS Modules。新規依存、外部画像、WebGL、Three.js、物理エンジン、外部フォント、音声、サーバー処理は使用しない。

Canvas 一枚で水面・影・404・葉を同じ時計と座標へ描画する。DOM は入力、説明、フォーカス、状態通知を担当する。生成画像を背景に貼る構成ではない。

## Implementation

### 水面と浮遊物

青緑のグラデーションと右上の暖色光の上に、シード付きの 420 個の不規則な曲面を重ねる。長さ・奥行き・明暗・位置を変え、風に従って移流・変形させる。光に近い部分だけ短く途切れた反射を描く。全面の均等な正弦波の線や粒子の点滅は用いない。

404 は自作の Path2D。薄い側面、接触影、水際の断片的な光と短い反射で浮遊感を表す。「0」と「4」の穴にも水面を見せる。各文字と葉は同じ surfaceAt 関数から水面の高さと傾きを取得し、位置による位相差を持つ。最大風でも文字が読める振幅に抑える。

葉は状態モデル内に 1 個だけ保持する。移動は共通風ベクトルに約 0.85 秒の慣性で追従する。画面端へ向かう速度成分だけを距離に応じて減衰させ、内側への速度には減衰を掛けない。反対側への再出現、中央への自動帰還、追加の葉の生成は行わない。

### 風と入力

- Pointer Events でマウスとタッチを統一。6px の遊びを越えると移動方向・速度から風を求める。
- 速度は画面短辺で正規化。ゆっくりしたドラッグにも小さな風力を与え、最大値は 1 に制限する。
- ユーザーの風は約 0.24 秒で入力へ追従し、解放後は時定数 1.45 秒で減衰する。
- 自然風はユーザー風と別に弱く変化し、合成した一つの風が水面・文字・葉へ作用する。
- 矢印キーを押している間はその方向へ送風。保持時間で徐々に強まり、斜めにも対応する。Escape で入力を解除する。
- タップ波紋は設けない。作品の操作領域だけで開始し、共通ナビゲーションを操作しても風を発生させない。
- キャンセル、capture 喪失、blur、非表示、リサイズで入力を解除する。

### 性能・アクセシビリティ

- 描画は約 30fps。DPR 上限 1.5、描画バッファ上限 180 万画素。パスは初期化時に生成し、毎フレームの画像ピクセル計算や重いぼかしを避ける。
- 毎フレームとポインター移動では React state を更新せず、モデルと Canvas を更新する。
- ResizeObserver でサイズと座標を管理し、葉の相対位置を保ちながら安全領域へ収める。
- 非表示・window blur で RAF を止め、復帰時に非表示の経過時間をまとめて積算しない。通常の積算も 50ms 以内へ制限する。
- RAF、Observer、イベント、Pointer Capture はアンマウント時に解除する。
- reduced-motion では葉と文字の移動、波の進行を停止する。入力による静止したさざ波の向き・明暗と風向表示は維持し、収束後は RAF を停止する。
- フォーカス表示、日本語の操作説明、操作開始・終了の status 通知を備える。連続的な風力をライブ通知しない。
- JavaScript なし／Canvas 利用不可では静的 SVG の水面・404・葉と共通ナビゲーションを残す。
- dark テーマと作品内部の上下の暗いベールで共通 UI を保護する。共通 CSS は変更しない。実ブラウザでの可読性評価は検証状況を参照。

## Lessons Learned

葉の端への減速を位置だけで両方向へ掛けると、逆風でも端から動き出せなくなる。速度の向きに応じて外側への移動だけを抑えると、張り付きと反転時の不自然な押し戻しを避けられる。

ユーザー風の減衰と葉の速度の減衰を分けることで、操作をやめた瞬間に葉が停止しない。弱い自然風も共通の環境状態へ加える。

## Reuse

入力速度の画面サイズによる正規化、方向別の境界減速、共通の風と物体固有の慣性の分離は、穏やかな漂流表現へ応用できる。作品をまたぐ共通エンジンには抽象化しない。

## Validation / limitations

現時点：新作の単体 5 件が成功。既存を含む 10 テストファイルの実行も成功。端への 10 分間の送風、四方向・4 画面サイズでの逆風復帰、弱いドラッグ、風力上限、解放後の慣性、30/60fps の差、reduced-motion を単体で検証した。

format、lint、型チェック、ビルド、E2E、実ブラウザの見た目、レビュー用画像・動画、CI は環境準備待ち。依存取得はネットワーク制限、Chromium 起動はサンドボックスのソケット制限で停止した。未実施の項目を確認済みとして扱わない。

本格的な屈折・鏡面反射・流体計算は行わない。元モックより水面の高低と反射の複雑さを抑え、厚みと接水感を簡略化する。実機 Safari／Android、実端末性能と触感は別途確認対象。
